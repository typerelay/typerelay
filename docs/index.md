## Build a useful snippet library

Start with text you already reuse: a customer reply, a meeting follow-up, a signature or a code example. Save the stable wording as a snippet, give it a recognizable title, and add an abbreviation if you want to expand it while typing. The [getting started guide](./guide/getting-started) walks through creating your first entry and using it on a connected desktop.

Choose Text for literal wording, Code for examples that must retain their syntax, and Rich text for formatted replies with links or images. Use [template variables](./guide/templates) when a name, date or other detail changes each time. Templates help keep the reusable wording together while leaving room to personalize each message.

## Choose your next step

For individual use, begin with a private library and a few frequently used shortcuts. For a team, organize approved replies into [shared libraries](./guide/libraries) and decide who can edit them. Our article on [shared snippet libraries for teams](https://typerelay.com/blog/shared-snippet-library-for-teams-one-source-always-current/) explains how to assign ownership and keep recurring wording current.

Install the [desktop app](./desktop/installation) to search and insert local content. Use the [terminal editor](./cli/tui) for a keyboard-focused editing workflow. Developers can build integrations with the [REST API](./api/) or connect compatible assistants through [MCP](./mcp/).

## Keep content available and recoverable

Read [sync and offline use](./guide/sync) before connecting another machine. Local libraries must be enrolled before they synchronize; exported files are separate copies, not live storage. The [import and export guide](./guide/imports) explains which format to choose when moving text or rich snippets with images.

Explore the [Typerelay feature overview](https://typerelay.com/features/) for product context, or use the [typing shortcuts guide](https://typerelay.com/blog/typing-shortcuts-for-reusable-replies-signatures-and-phrases/) for ideas you can turn into your first reusable replies.
