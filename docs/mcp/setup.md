# Setup

Configure the exact MCP resource URL and use OAuth sign-in, or a personal access token. Hosted MCP access requires an active Pro trial, Pro, or Team account; self-hosted installations are unrestricted. For development the endpoint is `http://localhost:3041/mcp`. Production requires HTTPS. Account permissions and OAuth scopes apply to every tool call; personal tokens receive every API scope. Revoke tokens and connected apps from **Settings → Apps Access**.
