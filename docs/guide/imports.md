# Import and export

Choose **Import** below the library list. TypeRelay YAML and SnippetsLab are supported; TextExpander CSV, Text Blaze JSON and recognized TypeIt4Me XML sets are Beta. Preview entries and correct abbreviations before saving. Imports create private libraries, never replace matching names. Unsupported macros become code without abbreviations and need review. Exported YAML is a portable copy; editing it does not synchronize changes.
