# Troubleshooting

Check the server URL, account permissions and device connection. If insertion cannot restore the original window, use Copy. Read-only libraries cannot upload edits. Revoked libraries leave active storage after the next successful sync, with unsent drafts preserved for recovery.

On macOS, continuous expansion listens to physical keyboard events. Apple Screen Sharing/VNC synthesizes input above the HID event tap, so panel insertion works there but abbreviation detection may not. Test continuous expansion locally or through a hardware KVM.
