# Installation

Use the repository installer for Omarchy and the matching panel package. The macOS package bundles **TypeRelay TUI**, opened from the menu-bar menu or Settings; both interfaces use `~/Library/Application Support/TypeRelay`. Credentialed local macOS test packages use the installed Developer ID Application identity so Accessibility remains granted after rebuilds and restarts; notarization remains part of the release workflow. The Windows installer includes the panel plus **TypeRelay TUI** in the Start menu; both use the same `%LOCALAPPDATA%\TypeRelay` database and sync credentials. Native macOS and Windows packages remain beta and may be unsigned. Preserve local settings and credentials when upgrading. See the repository delivery checklist for build details.
